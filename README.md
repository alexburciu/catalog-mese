# Colecția de dining

Catalog static pentru GitHub Pages. `index.html` și folderul `imagini/` trebuie păstrate împreună.

Pentru actualizare, regenerează catalogul cu `python catalog_mese_offline/build.py --skip-download`, apoi rulează `python catalog_mese_offline/prepare_pages.py` și publică fișierele din acest director. Imaginile provin din paginile comercianților.
